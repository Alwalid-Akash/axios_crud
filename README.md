# React CRUD App (Axios)

A simple CRUD (Create, Read, Update, Delete) application built with React using Axios and a fake REST API.

---

##  Features

- 📥 Fetch users (Read)
- ➕ Add user (Create)
- ✏️ Edit user (Update)
- ❌ Delete user (Delete)
- ⚡ Built using Axios for API calls


## 🌐 API Used

This project uses a fake REST API:

https://jsonplaceholder.typicode.com/users

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- Axios
- REST API
